### 🎯 What is FirstOffer?

**FirstOffer** is a platform built to help **students and freshers discover jobs, internships and off-campus opportunities in one place.**

Instead of searching across multiple Telegram groups, LinkedIn posts, company career pages and job portals, FirstOffer brings relevant opportunities together in a simple and searchable platform.

### ✨ Key Features

| Feature | Description |
|---|---|
| 💼 Jobs & Internships | Fresher-focused opportunities |
| 🎓 Batch-based Opportunities | Find roles relevant to your graduation year |
| 🏢 Company Opportunities | Startups and established companies |
| 📩 HR Emails | HR / recruiter emails wherever available |
| 📞 HR Contacts | Recruiter contact numbers wherever available |
| 📝 Direct Forms | Direct Google Forms shared by companies |
| 🔗 Application Links | Direct company application links |
| 🔎 Smart Search | Search by role, location and skills |
| ✨ Resume Matcher | Compare resume keywords with job descriptions |
| ⚡ Fresh Listings | New opportunities added regularly |
